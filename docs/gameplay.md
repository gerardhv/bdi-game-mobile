# Spelverloop

Het platform kan meerdere BDI-games hosten.

- Logistieke keten (`logistics`): [games/logistics.md](games/logistics.md) — stappen S00–S20, rollen, file en dossiers.
- Wie mag deze gegevens zien? (`access`): [games/access.md](games/access.md) — federatieve IAA in drie ritmes: eenmalig toetreden (BVAD), per zending betrokkenheid vastleggen (BVOD) en beleid, en bij elk verzoek controleert de Data Service Provider zelf token, lidmaatschap, betrokkenheid en beleid. Daarna een vervoerderswissel en een schorsing.

Hoe je een nieuw pack toevoegt: [games/README.md](games/README.md).
